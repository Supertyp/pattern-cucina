# Journey plan

Each journey is one dish (or one meal), in `src/content/journeys/<id>.md`. The steps are pattern ids in the order
you'd use them. Writers may reorder steps, or add or drop one or two where the dish needs it, but must keep every
pattern that is used nowhere else (checked by `scripts/check-journeys.py`).

Format: see the journey template in `src/pages/contribute.md`.
