# Pattern plan: 101 patterns

The master list of patterns, their ids, areas (clusters) and scope. The id is the file name in
`src/content/patterns/<id>.md`. Cross-links must use ids from this list only.

Types: `ingredient` (choosing, buying, storing or understanding an ingredient), `technique` (a concrete way of doing
something), `process` (an order of work for a multi-step task), `preparation` (what to plan, set up or check before you
start), `safety` (avoiding harm to people, food or equipment), `etiquette` (customs at the Italian table),
`pairing` (matching wine or drinks with food).
